# AMAZON CLONE

Hi! I'm Anirudh Gupta, a **cse student**. This is a clone of popular e-commmerce website **Amazon**.
I have created it with **Script** in frontend,  **HTML AND CSS** for backend 
<br>
<br>

<br>

## Features

- Register or login as an user.
- Update user account.
- Search products.
- Apply filters for searching products.
- Add products to cart.
- Change the required number for products.
- Payment with PayPal.
- Create order.
- Check order history.
